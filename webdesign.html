HTML 문서의 이해

- HTML 문서이다.
- HyperText Markup Language이다.
- Hyper Text는 글자를 클릭하면 다른 문서로 연결되는 기능을 말한다.
- Markup Language는 간단한 태그로 사용하는 프로그래밍 언어를 말한다.
기본 태그 요약 및 맛보기

- h (Head line) : 제목체를 만들어 준다. (숫자 1~6)
    코드: <h1>가장 큰 제목</h1>
    결과:

가장 큰 제목

- b (Bold) : 굵은 글씨를 만들어 준다.
    코드: <b>굵은 텍스트 표현</b>
    결과:
굵은 텍스트 표현
- i (Italic) : 이텔릭체 기울임꼴을 만들어 준다.
    코드: <i>기울임꼴 텍스트 표현</i>
    결과:
기울임꼴 텍스트 표현
- u (Underscore) : 밑줄을 만들어 준다.
    코드: <u>밑줄 텍스트 표현</u>
    결과:
밑줄 텍스트 표현
포트폴리오 핵심 레이아웃 및 인터랙션 명령어 모음

- hr (Horizontal Rule) : 수평선을 그어 영역을 분리해 준다.
    코드: <hr width="80%" align="left">
    결과:
- center : 내용을 화면 정중앙으로 정렬해 준다.
    코드: <center>중앙 정렬 텍스트</center>
    결과:
중앙 정렬 텍스트
- mark : 핵심 키워드에 형광펜 하이라이트 효과를 준다.
    코드: <mark>최우수 역량</mark>
    결과:
최우수 역량
- details / summary : 클릭하면 내용이 펼쳐지는 아코디언 메뉴를 만든다.
    코드: <details><summary>제목</summary><p>상세 내용</p></details>
    결과:
클릭해서 펼치기

숨겨져 있던 상세 내용이 나타나는 인터랙션.

- input type="range" : 드래그하여 수치를 조절하는 슬라이더 인터랙션을 만든다.
    코드: <input type="range" min="0" max="100" value="75">
    결과:
작업 진행도 조절: (75%)
포트폴리오 핵심 스타일(CSS) 원리 정리

- border-radius (모서리 둥글게) : 딱딱한 사각형 모서리를 부드럽게 깎아 시각적 안정감을 준다.
    코드: border-radius: 15px;
    결과:
오직 둥근 모서리만 적용된 박스

- box-shadow (입체 그림자) : 평면 박스에 은은한 그림자를 주어 화면 위에 떠 있는 듯한 깊이감을 만든다.
    코드: box-shadow: 0 6px 20px rgba(79, 59, 51, 0.25);
    결과:
오직 입체 그림자만 적용된 각진 박스

- flexbox (유연한 좌우 정렬) : 여러 요소를 줄바꿈 없이 가로로 나란히 정렬하고 유연하게 배치한다.
    코드: display: flex; gap: 10px;
    결과:
